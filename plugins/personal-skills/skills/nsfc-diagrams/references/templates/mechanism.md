# 视觉风格与版式规范

## 参考图的视觉逻辑

基金图首先让评审看清对象、方法与关系。优先采用实验照片、简洁黑色轮廓图标、方框模块和实心箭头。阅读方向稳定，同类项排齐，文字与图形紧密对应。彩色用于表示类别或更新阶段，而不是装饰。

两类参考结构分别使用：

| 图形类型 | 组织方式 |
|---|---|
| 场景与技术流程图 | 图片或输入集合、方法模块、输出；短实心箭头连接，反馈沿图外缘用直角线路返回 |
| 多层次评估图 | 层次标题、评估维度、评估内容；用包含与分叉线表达层级，保持同层同色 |

不要把分层评估误画成顺序执行，也不要把对照图片画成互相转化。模板中的机器人、数据库、因果特征等元素只在本图有对应含义时复用。

## 整体排版

1. 保留用户草图的拓扑关系，先确定模块网格。流程横向或纵向择其一作为主阅读方向，避免任意斜向发散。
2. 同级照片统一比例、大小及裁切；不得拉伸图像。标签与照片共享中心线。同一任务变化组尽量使用相同机位。
3. 并列分支顶部排齐。输入集合可用细括线或包围框汇集，再分支到各模块，避免连接线看似只从某张照片出发。
4. 模块内文字、图标与照片均留出安全内边距。连接线路径预留独立通道，不能穿过文字、图标或照片。
5. 页面边缘留统一余量；模块间空隙通常大于模块内空隙。视觉主体应连续，不出现上半部密集、下半部大面积空洞的失衡。
6. 图片多时优先减少重复标签、缩短句子或调整图形长宽比。缩小字体是最后选择，不能牺牲评审阅读。

可从以下画布比例开始调整，而非固定要求：边缘余量约画布宽度的1.5%–3%，模块间隔2%–4%，图片与标签间距约半个字高。同一层级的间隔一致比绝对值更重要。

## 字体与文字

图面默认不放解释句；确有必要时每模块最多一条短注。把完整论述留在正文，将图面文字限制为对象、模块、必要参数、关系与状态。通常2—8字，必须保留能区分含义的限定词，例如“推理开销”“工具调用”“结果返回”。不要为了减字写成不明对象的“调用”“返回”，也不要为了填空添加同起点、等预算等说明。已在视觉结构中明确表达的关系不再重复成句。

有共同含义的分组加简短容器标题；标题可放框外或用背景留白嵌入边框，必须让边线避开文字。不要用大面积彩色标题条替代层级组织。

| 元素 | 默认处理 |
|---|---|
| 中文 | 宋体 / SimSun；缺失时选本机可用且笔画清楚的中文衬线字体 |
| 英文与数字 | Times New Roman 或与中文协调的衬线字体；必要术语如 Sim-to-Real、CKA 保留 |
| 模块标题 | 同一字号，可适度加粗，不使用过大黑体标题抢占图面 |
| 图片标签 | 一行或两行，字数和断行模式一致；按意义断行，避免单字孤行 |
| 连线说明 | 短词组，靠近对应线段且不压在线上；不塞入实现步骤 |
| 图题 | 在目标 Word 中排版，保持文档既有宋体、字号、居中格式与编号 |

按最终使用尺寸计算字体，而不是凭SVG像素值判断：

`印刷字号(pt) = SVG字号 × 使用宽度(cm) × 72 / (2.54 × viewBox宽度)`

图内正文可从10.5–12 pt、标题12–14 pt开始；辅助说明尽量不低于9 pt。若特定模板字号较小，必须实尺寸检查，不能通过单纯复制模板像素字号得到可读性。

例如图宽15 cm、viewBox宽1600时，40个SVG单位约为10.6 pt。较复杂大图可能需要扩大使用宽度或拆图，而不是降低字号。

宋体缺乏真正粗体时，检查渲染后的合成粗体是否糊成一团；必要时用正常字重、标题字号差或框线区分层级。不要用emoji替代图标。

## 连接符与箭头

| 关系 | 建议图形 | 注意事项 |
|---|---|---|
| 输入、输出、任务推进 | 黑色单向实心三角箭头 | 起终点对应对象边缘，指向清楚 |
| 并列分支 | 共用直角母线，再分别单向连接 | 母线不表达额外顺序，均匀分配支路 |
| 反馈 | 外侧直角回路，单向箭头，短标签 | 不覆盖主体或制造无依据闭环 |
| 层级分类 | 无箭头细分叉线或包含容器 | 不是时间序列，避免用箭头暗示推进 |
| 成对对照 | 细连接、双向箭头或相邻对照排列 | 双向箭头只用于互相对照、映射等有明确含义的关系，不代表两种场景实际转换 |
| 难度轴 | 简单单向线，端部标易与难 | 任务已用短箭头串联时，难度轴仅表示等级，不重复复杂流程 |
| 状态移位示意 | 虚线原位置、实线新位置、短箭头 | 图标内部语义明确，勿让虚线污染整个流程 |

主箭头采用一致的杆宽和头部。可按最终印刷尺寸取主线1–1.5 pt、模块边框0.6–0.9 pt、辅助线0.4–0.6 pt；头长约杆宽的3–4倍，头宽约杆宽的3–4倍。确保SVG和可编辑源文件的比例一致。

布线顺序：先标出起终点及方向，给主流程、分支、反馈各留通道，再放模块，最后绘线。反馈优先沿外缘；交叉时先移动接口、调整间距或通道，确实无法避免且不会误读时才用跨线桥。有连接的交点可加实心节点，无连接线路避免相交。不同分支只有在后续语义一致时才合并；合并前保留结果标签。主流程用黑色，模块内部可用语义色突出继续路径、灰色表示停用。

箭头在对象边界结束，不能伸进文字；连线标签与线段分离，按最终字号留出至少约半个字高的间隔。长标签先调整路径和端点，不压缩字体。接受/拒绝、继续/停止等状态可采用矢量勾叉、路径与标签联合表达，避免仅靠颜色。优先显式三角形箭头，使用marker时必须验证导出后的方向和尺寸。

默认直角、直线、方形端部。斜线只用于确有必要的空间关系或用户明确的草图；不以斜线作为方便连通的捷径。没有特别含义时不使用曲线、空心大箭头、多彩连接线或渐变进度条。

双向箭头、marker、嵌套SVG等实现须实际渲染核对，防止方向相反、头部裁切、文字与图标重叠。箭头不应仅靠颜色区分。

## 配色

默认使用下列机制图色板，适用于各类基金图；有用户指定参考时按参考。使用3—4种具有明确语义的强调色作为可选范围，不强行用满。颜色用于小面积形状、节点、路径或状态，白底与黑色轮廓保持整体克制，不把所有标题和大容器同时填满颜色。

| 色彩 | 色值 | 可采用的含义（按本图确定） |
|---|---|---|
| 蓝 | `#56A9E0` | 模型、训练、选中的路径 |
| 绿 | `#9CCC65` | 数据、记忆、保留状态 |
| 黄 | `#F2C14E` | 验证、资源、配置参数 |
| 红 | `#E87878` | 停止、拒绝、恢复或需关注的变化 |
| 灰 | `#B7BEC3` | 未选择或停用的路径 |

以上含义不是跨项目固定映射。先定义本图颜色对应的对象或状态，同一局部同一颜色保持一致；颜色含义不能由位置推断时，添加必要短图例。相似颜色不承担需要精确区分的类别。状态同时用符号或标签区分，黑白打印仍需可读。

浅色只作为背景、分组或用户参考的备选色：

| 用途 | 默认色值 |
|---|---|
| 背景 | `#FFFFFF` |
| 文字、主连线、轮廓 | `#191919` |
| 图片细边框、次级辅助线 | `#555555` 或 `#737373` |
| 浅蓝模块 / 评估维度 | `#D6EDF5` 或 `#E0EDF6` |
| 浅红模块 / 层次标题 | `#F6DEDB` 或 `#F8DDDD` |
| 浅橙评估内容 | `#FAE5D3` |
| 层级图柔和外容器 | `#DCE4F3` |

采用白底方框作为流程图基本构件；浅色标题条仅在需要明确分组时使用。评估层级图可以沿用模板的圆角大容器，但不要把所有研究图统一改成圆角卡片。

可按模板在小面积图标或确有区别的训练阶段使用较鲜明蓝、红；不把主线路径和所有标题同时上色。黑白打印时仍应由文字、形状和位置辨认结构。

## 示意元素

先确定对象与操作，再选择形状：训练策略与超参数配置用折角文件，经验和记忆用存储结构，模型用网络或层结构，候选筛选用具名分支，交互用对象与往返关系。工具图标要足够大，使缩小后仍能辨识操作，不用小图标装饰大段文字。

神经网络、特征阵列等抽象形状仅在所表示对象确为网络或特征时使用。不能把配置文件误画成样本块，也不能把明确候选流程改成不具名的方块链。智能体可按用户参考使用机器人轮廓、模型或其他适合对象，机器人和雷达均不是必选模板。雷达、曲线、柱条若无数据依据只表达结构，不绘制暗示实测优劣的性能序列。

图标表现对象或机制，不承担整段正文。选择“看图就能解释”的元素：物体及虚线原位表示扰动，带逐步增加子步骤的任务卡表示任务递进，物体与两种接触表面表示物理迁移，框内菱形阵列可表示特征。

复杂设备轮廓优先使用可识别的规范图形或用户已有素材。自绘时用一致轮廓粗细、明确的接触与支撑、少量内部细节；避免仅堆叠方块、用滑块代替所有变化、用阶梯代替所有学习机制。

图标应作为矢量轮廓组合，优先保留形状编辑能力。若因兼容需要作为独立SVG图标嵌入，应保留其源定义，不将其栅格化。只在参考图确实需要时增加图标，不能为了填补空白插入无意义元素。

## 机制模板的字体、配色和容器

以下是从参考归纳的可执行默认值，不声称是原文件精确字号/取色。EMF中字体不一定能可靠提取，以实际渲染为参考。

- 图内主要模块标题：宋体加粗，按最终印刷约11–12pt；操作标签：宋体常规10–11pt；图例/辅助：9–10pt。用户要求统一无衬线或已有图为无衬线时沿用，不强制换宋体。
- 主标题/普通标签用#20272C，重点对象可用对应分支色；不要采用框架图的大面积蓝色编号标题栏。
- 蓝#56A9E0用于特征/模型，绿#9CCC65用于样本/记忆，黄#F2C14E用于候选/条件，红#E87878用于差异/失效。每图先定义语义；红色选区只有真的选择/异常含义才画。
- 外围流程分组：白底黑灰细框，按内容可小圆角；平行分支可用与分支一致的细虚线框。内部模块以白或浅色填充，避免每个图标都加框。
- 主流程约1–1.5pt黑色实心箭头，辅助约0.5–0.75pt；共享参数/非直接数据流可用虚线并附短标签。接口与交点必须可判别。
- 参考中的照片堆叠、特征立体层和网络节点是对象表达，不应一概当作装饰3D而禁止；仅当确实表达层/张量等对象时使用，避免装饰性立体箭头。

绘图前在规格中注明所选M-A至M-E、具体asset ID、借鉴局部与不借鉴部分。参考内容有不清晰文字时不猜；M7禁用为文字参考。
