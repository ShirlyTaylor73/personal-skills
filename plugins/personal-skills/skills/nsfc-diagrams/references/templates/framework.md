# 总体框架图模板

用于研究内容分工、模块关联和共同支撑。先核对完整研究内容及方案，提取每块研究什么、输出什么、如何关联，再确认大体结构。主体用具体对象和简化机制表达，不把正文塞成文字框。

## 构图

按并行、递进、闭环、基础设施等关系选横向并列、上下分层或上部主线＋底部支撑。上三下一只是示例，不固定四块、不强加闭环。同级默认等宽，特殊比重依据用户要求。默认无总体目标条、科学问题层及解释段落。

先制作独立场景和机制元素，检查关键局部，再组装。优先复用干净素材，不嵌入缩小的整幅旧机制图。预留宽箭头及关系文字通道，标签横排或按词组分两行，空间不足时重排整体，不默认逐字竖排。

| 元素 | 颜色与样式 |

| 标题带 | #124C70→#1762AC轻度渐变，白色加粗标题 |
| 斜切衔接 | #002E5C |
| 内部小标题 | **#0E2841，微软雅黑加粗** |
| 普通标签 | #20272C，微软雅黑常规 |
| 前向关系文字 | #A52429，微软雅黑加粗 |
| 返回关系文字 | #20272C，微软雅黑加粗 |
| 共同支撑关系文字 | #124C70，微软雅黑加粗 |

标题带跨接模块上边框，约一半在边框上方；编号、底色、斜切和文字整体移动。两端可略内缩以露出框角，反馈在标题边缘结束，不穿文字。必要时每模块最多一条浅灰蓝#EDF2F4短摘要带，默认不加。

参考PPT编号36pt、主标题30pt、内部小标题28pt、辅助24pt、关系28.5pt为比例依据，不能直接套用不同尺寸。“可演化专家”20pt为特定局部，不推广。禁止全图同字号或全加粗。主标题约1.07倍小标题，辅助约0.86倍小标题；按最终印刷尺寸核对。内部小标题为藏蓝#0E2841，不是支撑关系用的#124C70。解析主题的方法见[风格索引](../style.md)。

## 关系和语义色

前向跨模块采用浅红#F0DBDC→#CE8C91渐变宽箭头与暗红标签；返回用#657C8E外缘线路，公共支撑用#A6B3C6母线及端部箭头；内部过程用细深蓝或黑色箭头。分类用包含或无箭头分叉。

参考只决定样式，不新增双向关系、顺序或闭环。保留能力分区、轨迹、记忆和激活状态的语义颜色，不全改蓝色。渐变限于标题带与关系箭头，不增加阴影、发光或3D装饰。

## 检查与素材

检查主线与支撑是否可辨、来源与筛选是否正确、记忆与模型学习是否混淆。检查标题跨框、端点、组外连线、图层及字宽。目标印刷宽度不足时先简化信息或改布局。

[样例与组件](../../assets/README.md)提供三模块示例。模块数、是否存在基础设施、是否闭环均由实际研究决定，组件没有固定研究含义。

## 明确的素材路由与可选边框风格

先读[真实素材索引](../../assets/README.md)，打开F1及其title-style、relation-arrows、internal-hierarchy局部，作为默认框架图视觉依据；需要多块研究与平台组织时再看F2。F3聊天截图只参考标题/箭头/边框，不参考纯文字内容结构。本包无F3原始图像文件，不得声称已收录。

| 画法 | 对应素材 | 标题/边框 | 排版 |
|---|---|---|---|
| F-A 默认编号蓝带 | F1＋标题/关系/内部层级局部 | 本文件明确色板，编号斜切、跨框蓝色标题带；主体细深灰或深蓝边框 | 等级一致的研究块，通道容纳关系标签和宽箭头；块内保留机制 |
| F-B 多研究块与共同平台 | F2＋F1文字风格 | 默认沿用F-A字体色板；可用小面积不同色细轮廓区分研究类别 | 模块内部放简化机制，共同平台用支撑关系，不固定上下数量 |
| F-C 白底圆角边框 | F3（仅用户明确指定时） | 白底、黑色圆角外框；蓝色编号、藏蓝粗体标题，虚线分组，蓝灰关系箭头 | 仅替换外观，仍需要具体场景/机制，不能退化为长句文字框 |

F-C建议编号#1762AC、标题#0E2841、辅助#20272C、边框#20272C、组框#888888；这些为依据截图制定的建议值，不是原图精确取色。框架默认仍为用户已确认F-A，不随素材增多自动混用。

各层字体比例、配色见本文件前表；外框按印刷0.6–0.9pt，机制内部0.4–0.7pt，反馈0.8–1.2pt；宽箭头用形状占通道，不简单加粗细连线。标题条和摘要条不叠加冗长说明。使用F2只借鉴研究模块内部有机制及跨模块联系，不复制其密集的小字和内部缩略整图。
