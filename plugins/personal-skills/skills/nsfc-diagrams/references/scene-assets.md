# 场景素材规划与生成

## 素材表

在调用生成工具之前，确定每个位置展示什么、与其他图片如何比较。推荐记录以下字段，无需为简单图建立复杂配置系统：

| 字段 | 内容 |
|---|---|
| 图片位置 | 初始场景、对照组上图、递进任务等 |
| 场景与任务 | 明确到对象、动作及环境 |
| 标签 | 将在SVG中单独添加的短中文 |
| 来源 | 用户实拍、仿真截图、生成或编辑 |
| 基准素材 | 复用哪张图、是否需要编辑 |
| 改变项 | 位置、材质、光照、干扰、接触表面等 |
| 保留项 | 机器人、视角、目标、布局、初始状态等 |

## 受控生成流程

1. 统一机器人形态、实验环境、相机角度、照片比例与光照。若用户已选定桌面固定机械臂，不擅自引入移动平台、户外场景或人形机器人。
2. 先生成基准图，检查镜头、对象大小和物理合理性。缩小为图中小图片时仍应辨认任务目标。
3. 用基准图编辑生成变化图。同一对照组主要改变一类因素；综合难度组可以组合变化，但标签应准确说明。
4. 相同图片在不同区域复用，不为“无干扰”“简单任务”等重复位置重新生成。
5. 检查物体支撑、机械臂关节、夹爪接触、遮挡与可达性。生成失败时只针对发现的问题修订，不随意重构整个场景。

图片里的材质只能示意属性类型；未经设定的质量、摩擦系数、测量精度等不能从视觉推断后写成数值。生成照片不能作为性能结果或真实实验记录。

## 本用户环境中的生成路线

用户已明确指定 imagegen 官方 CLI 路线与 `gpt-image-2.5`；该技能复用于同类基金图时沿用此偏好，用户最新指定可覆盖。先阅读环境中可用的 imagegen 技能及 CLI 文档，调用其提供的脚本，不另外编写图片API客户端，也不修改技能原脚本。

用户级 `${CODEX_HOME}/config.toml`，或 `CODEX_HOME` 未设置时的 `~/.codex/config.toml`，可在 `shell_environment_policy.set` 中配置 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL`。这是一种配置来源，不保证每个环境都存在。只在需要时读取并注入当前生成进程，不回显、写入提示词、提交Git、导出或修改凭据。无需凭空要求用户再次提供已存在的配置。

在适合环境的独立Python依赖目录补齐官方CLI所需包。默认高质量PNG、`1536×1024`横向图片；比例由图中实际图片框决定。先验证生成接口，再验证编辑接口，不假定兼容接口支持所有模型与参数。

使用官方脚本的示意命令，路径和参数以实际版本为准：

```text
python <imagegen技能提供的image_gen.py> generate --model gpt-image-2.5 --prompt-file <基准图提示词.txt> --quality high --size 1536x1024 --output-format png --out <基准图.png>
python <imagegen技能提供的image_gen.py> edit --model gpt-image-2.5 --image <基准图.png> --prompt-file <变化图提示词.txt> --quality high --size 1536x1024 --output-format png --out <变化图.png>
```

不要自行换模型、接口、图像生成路线或从用户订阅切到API付费路线。既有授权不覆盖未说明的其他服务。接口明确拒绝指定模型或编辑请求时，报告具体问题并保留已完成素材；只有临时故障才作有界重试，先检查输出文件，避免重复付费生成。

在未指定这条CLI偏好的其他用户环境中，按当地可用工具和用户选择确定路线，不把本用户配置写成全局强制要求。

## 提示词模式

提示词重点是场景清楚、生成可控，不让生成模型负责整个基金图。

**基准图**

```text
用途：科研基金研究方案中的单张写实实验场景示意，非信息图。
任务：桌面固定机械臂抓取放置；红色目标物与蓝色托盘清楚可见。
画面：固定略俯视的前方三分之四镜头，简洁实验台，柔和自然实验光照。
约束：机械结构合理，物体稳定支撑；主体在小图中可辨。
不生成：文字、标签、箭头、边框、品牌、水印或多图拼贴。
```

**配对图编辑**

```text
输入图是编辑目标和机器人身份参考。
只改变：将目标物起始位置移动到指定位置。
保留：机械臂、夹爪姿态、实验台、托盘、镜头、光照及其他对象。
目标：同任务的受控位置对照，物体可见且可操作。
不生成：文字、箭头、图表、边框或额外场景。
```

**跨场景迁移编辑**

```text
只改变接触表面为薄层覆砂台面，保留同一箱子、机器人、起始位置与推移方向。
保持桌面固定机械臂，不改为户外沙地或移动机器人。
显示可辨认的接触表面差异，不额外假定试验数值或效果。
```

若需要不同任务导致动作姿态变化，应明确允许这些变化，而非承诺图像逐像素一致。

## 素材保存

保存原始图片、最终提示词、素材与图中位置对应表。组装SVG时可使用合适尺寸的内嵌副本以控制体积，原始PNG不覆盖。格式转换不应导致目标物、材质差别或细小接触过程丢失。

只需修改矢量风格时不重新生成照片。素材数量、具体操作类别和12图15位置等均是项目选择，不是通用固定模板。
