# 风格索引与共用原则

按用途读取[机制模板](templates/mechanism.md)或[框架模板](templates/framework.md)。字体、标题背景及箭头粗细按模板选择，用户参考优先。

## 版式与字号

统一基线、同类对象尺寸及内边距。图片不拉伸，先留连接通道。短标签保留关键限定词，分类、过程和反馈不混用。以实际渲染验收，不用颜色数量、形状数量代替可读性。

印刷字号(pt)=SVG字号×使用宽度(cm)×72/(2.54×viewBox宽度)，另乘局部缩放。PPT字号取相对比例，不能脱离画布尺寸直接套用。文字密集先改布局与重复信息，不无限缩字。

## 参考PPT主题解析

读取当前幻灯片、布局、母版及主题的关系，解析有效clrMap/overrideClrMapping，再解析schemeClr及tint、shade、lumMod、lumOff等修饰。字体同样检查有效继承。未支持的修饰需用Office渲染对照，不能猜值。

已核对参考的tx2→dk2→#0E2841，无额外明暗修饰。tx2不是通用固定色，也不是默认黑色。输出采用解析后的明确RGB色，防止Word/PPT主题变化。换字体后重新检查字宽、基线、行高和底部截断。
